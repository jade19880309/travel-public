STOB

使用說明

把旅遊訂單交給自己的 Claude 整理成行程，再做成 PDF 或網頁給同行的人。

是什麼第一次使用上傳訂單看行程行程・PDF・網頁管理與備份儲存狀態隱私與問答

STOB 是什麼

STOB 是放在你自己 Claude 帳號裡的旅遊訂單本：把機票、飯店、交通的確認信或截圖丟進去，它會自動整理成行程表，還能排建議行程、做成 PDF 或網頁分享給同行的人。

  • 資料只在你的帳號：訂單和成員資料存在你自己的 Claude 帳號，別人（包括給你檔案的人）都看不到。
  • 用你自己的 Claude 額度：讀訂單、排行程都是你的 Claude 在做，不會傳到其他服務。
  • 分享出去的不含個資：發佈給同行的人的網頁和 PDF，不會放姓名、護照、PNR、訂單編號、電話等資料。

第一次使用

安裝只要做一次，之後從 Claude 的網頁列表打開就好。手機、電腦都可以，資料會自動同步。

  1. 打開安裝頁。
  2. 到 Claude 的「設定 › Capabilities」，打開「程式碼執行與檔案建立」（Code execution and file creation）。安裝頁有按鈕可以直接開。
  3. 在安裝頁按「複製」，到 Claude 開新對話，貼上送出。Claude 會幫你建立「STOB 旅遊訂單」網頁並給你網址。
    • Claude 抓不到檔案時，在安裝頁按「下載 STOB.html」，把檔案附加到同一個對話。
  4. 之後從 Claude 的 artifacts 清單找「STOB 旅遊訂單」打開。第一次上傳訂單時，Claude 會問要不要允許這個網頁使用 Claude，按「允許」。

LINE 不能傳 .html 檔，要給別人安裝時，傳安裝頁網址就好。

前往安裝頁

上傳訂單

按右下角 ＋ 上傳訂單，把確認信交給 Claude 讀，你確認後才會存入。一次通常 20–90 秒。

  1. 選檔案或貼文字：可以一次選多張訂單截圖、PDF，或直接貼上確認信文字。想提醒 Claude 的事寫在「補充說明」，例如「這是媽媽的票」。
  2. 看預覽：「讀到的內容」會列出旅程、旅客和每筆訂單。可以改旅程名稱、把訂單放進已有的旅程，或取消勾選不要的人和訂單。
  3. 按 ✅ 存入。不對就按「← 回上一步」重讀，或「放棄」。

小提醒

  • PDF 只讀前 4 頁，很長的確認信建議截重點頁。
  • 訂單截圖會一起存到雲端。如果沒存成功（例如空間滿了），上傳頁最上方會列出是哪張、為什麼，可以按「重試」。訂單資料本身已經存好。
  • 存入後發現有錯，到「管理」修改就好，不用重傳。

看行程

底部五個分頁各管一件事。「清單」是給自己看的總表；「個人單」是給每位旅客本人的；要給全部同行的人看，用後面的「發佈成網頁」。

分頁做什麼含個資給誰看
清單依旅程看全部訂單；上方切換成員、機票、飯店、交通、其他、行程、費用有自己
未付款還沒付的訂單、付款期限和免費取消日有自己
個人單一人一張：英文姓名、護照、自己的航班與 PNR、住宿與同房人、自己要付的費用；可存成圖片有（只有本人的）那位旅客本人
確認信各筆訂單的確認信狀態有自己
管理上傳、修改、備份（見「管理與備份」）有自己

右上角 店家報到 把航空、飯店、交通、餐廳門票的報到資料放大顯示，在櫃檯直接拿手機給工作人員看。

個人單存圖：按存成圖片後，長按圖片選「儲存到相簿」或「分享」，再私訊傳給那位旅客。圖上有護照和 PNR，不要丟到群組。

建議行程、PDF 與分享網頁

在「清單 › 行程」選一趟旅程，Claude 會根據已訂的航班、飯店、交通排出每天的建議行程，再做成 PDF 或網頁給同行的人。

排建議行程

  1. 先打開「偏好設定」填節奏、想去的地方、有沒有小孩長輩，再按產生。
  2. 結果是每天一個大綱加細項。整份不滿意按「重新產生整份」，只改一天用那天的「重排」。
  3. 小修改用「用一句話修改行程」，例如「第三天改去迪士尼」。單一項目可以直接刪除；整份不要了按「刪除行程」。

下載 PDF

按 下載 PDF。順序固定是航班 → 飯店 → 交通 → 每日行程（先大綱再細節）→ 注意事項，適合列印或用 LINE 傳。手機不能下載時，會改成圖片顯示，長按儲存。

發佈成網頁

按 ⬇️ 下載網頁檔，會產生一個 .html 檔，對方不用 Claude 帳號就能打開；行程預設折疊，配色每次隨機。

  • 下載前會檢查個資：如果行程說明或提醒裡寫到姓名、護照、PNR、訂單編號、電話、身分證字號、卡號、Email，會先列出來。按「遮蔽後下載」會換成「＊＊」，你原本的資料不會變。
  • 下載失敗時：按「再試一次下載」，或「複製網頁原始碼」貼到記事本另存成 .html。兩者是同一份已檢查過的內容。
  • 怎麼傳：LINE 不能傳 .html 檔。用 AirDrop、Email 或雲端硬碟傳網頁檔；只能用 LINE 的話，改傳 PDF。

管理與備份

「管理」頁最上面是「用一句話修改」，下面四個分頁：旅程、成員、訂單、備份。

用一句話修改

直接打想改的事，例如「京都那間飯店改成已付款」「把小明加到東京所有訂單」。Claude 會列出每一項「哪筆資料・哪個欄位：舊值 → 新值」。

  • 只會套用你勾選的項目。
  • 格式不對的項目（例如日期寫錯、金額不是數字）會標紅，不能勾。
  • 刪除類預設不勾，確定要刪才自己勾。

旅程、成員、訂單

  • 旅程：名稱、日期、外幣、住宿費是否按分組平分。刪除旅程會連帶刪掉裡面的訂單。
  • 成員：英文姓名、護照會自動轉大寫。「分組」填一樣的人算一家，費用分攤和個人單會依分組。
  • 訂單：可改所屬旅程、狀態、付款；「進階」可直接改資料，格式不對會告訴你哪個欄位有問題，不會存。

表單填到一半不會因為畫面更新而清掉；儲存、取消按鈕固定在畫面底部。

備份與還原

資料已經自動存在雲端。重要的時候（例如大改之前）可以另外留一份：

  1. 按 📋 複製全部資料，貼到記事本存起來（不含訂單截圖）。
  2. 要還原時，貼回「還原」框，按「檢查備份」。會顯示目前和還原後的旅程、成員、訂單數量。
  3. 勾「我了解目前的資料會全部被取代」，再按「確定還原」。
  4. 還原錯了，在同一頁按「↩︎ 復原到還原前」。重新整理頁面後就不能復原。

備份裡有護照等個資，請存在自己的裝置，不要傳到群組。

儲存狀態與「暫停儲存」

每次修改都會自動存到雲端，標題下方的小標籤告訴你有沒有存到；沒有標籤就代表已經存好。

標籤意思怎麼辦
讀取中…／儲存中…正在讀或存等幾秒
⚠ 未儲存網路不穩，或另一台裝置正在存不用動，會自動重試；網路恢復就會補存。先別關掉頁面
⚠ 未登入沒登入 Claude，或不是在 Claude 裡打開登入後從 Claude 的 artifacts 清單重新打開
⚠ 已暫停儲存為了不覆蓋資料而停下：別的裝置或分頁更新過、雲端資料讀不完整，或 Claude App 太舊看畫面上方的紅色提示，照下面步驟重新讀取

重新讀取

暫停儲存時，所有修改都會被擋下，避免你以為存了其實沒存。

  1. 按紅色提示裡的「重新讀取」。
  2. 會先問你確定嗎：重新讀取會改用雲端最新資料，這台裝置還沒存上去的修改會遺失。
  3. 不確定就先按「先複製目前資料」，貼到記事本；之後可以用「備份 › 還原」拿回來。
  4. 按「確定重新讀取」，或「取消」維持原狀。

提示寫「不支援儲存鎖定」時，是 Claude App 版本太舊，先更新 App 再打開。同一時間最好只在一台裝置修改。

隱私、注意事項與常見問題

隱私

  • 訂單、成員、護照只存在你自己的 Claude 帳號。把 STOB 網頁分享給別人，對方打開看到的是他自己的空白資料，不是你的。
  • 會帶個資的只有：個人單圖片、備份文字。這兩樣只私下傳給本人。
  • 發佈的網頁和 PDF 不含個資，可以丟群組。
  • 「勾選採用」、個人單選項、確認信狀態存在各台裝置，不會跨裝置同步。

常見問題

免費方案可以用嗎？
讀訂單、排行程會用你的 Claude 額度，額度用完就要等恢復。能不能建立網頁依 Claude 當時的方案而定，安裝時 Claude 會告訴你。
讀出來的資料不對？
預覽時先改；已存入就到「管理」用一句話修改，或在「訂單」分頁編輯。
換手機或用電腦開？
用同一個 Claude 帳號打開同一個 STOB 網頁，資料就在。不要重新安裝一份，那會是空的。
頁面一直顯示「已暫停儲存」？
照「重新讀取」的步驟做；讀取還是失敗，先確認網路，稍後再試。這時雲端上的資料沒有被動到。
下載的網頁檔怎麼開？
對方在手機或電腦點兩下用瀏覽器開就好，不用上網也看得到內容；地圖連結需要網路。
