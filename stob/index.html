安裝偏航 DETOUR

把偏航 DETOUR 裝進你自己的 Claude，訂單截圖丟進去就會自動整理。只要做一次，約 2 分鐘。

1

先開啟 Claude 的一個設定

需要 Claude 帳號。到 Claude 的「設定 › Capabilities」，打開「程式碼執行與檔案建立」（Code execution and file creation）。

打開 Claude 設定
2

複製這句話

請照 https://raw.githubusercontent.com/jade19880309/travel-public/main/stob/INSTALL.md 的說明，用程式碼執行下載 https://raw.githubusercontent.com/jade19880309/travel-public/main/stob/DETOUR.html ，原封不動發佈成我的 Claude 網頁「偏航 DETOUR」。

已複製。沒複製成功的話，長按上面的文字全選後複製。

3

到 Claude 開新對話，貼上送出

Claude 做好會給你一個網址，點開就是你自己的偏航。之後從 Claude 的 artifacts 清單找「偏航 DETOUR」打開。

打開 Claude

第一次上傳訂單時，Claude 會問要不要允許這個網頁使用 Claude，請按允許。

Claude 說拿不到檔案？

按下面的按鈕把檔案存到手機，回到剛剛的 Claude 對話，用「＋」附加這個檔案再送出一次。

下載 DETOUR.html
要注意什麼？
  • 訂單資料只存在你自己的 Claude 帳號，分享給你的人也看不到。
  • 讀訂單、排行程用的是你自己的 Claude 額度；免費版額度較少。
  • AI 可能讀錯，存入前核對日期、時間、金額和訂位代碼。
  • 不要上傳有完整信用卡號的截圖。
  • 如果 Claude 說這個帳號不能建立網頁，請告訴分享給你的人。
